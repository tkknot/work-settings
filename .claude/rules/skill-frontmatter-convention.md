# SKILL.md frontmatter 規約

`.claude/skills/*/SKILL.md` の frontmatter に書くフィールドの規約。ファイル名・ディレクトリ名は
`file-naming-convention.md` を参照。

| フィールド | 必須 | 内容 |
|---|---|---|
| `name` | 必須 | ディレクトリ名と一致させる |
| `description` | 必須 | 何をするスキルかを1行で。Claude が起動判断に使う |
| `argument-hint` | 引数を取る場合 | `/` メニューのオートコンプリートに表示する引数のヒント |

## `argument-hint` の記法

- 角括弧 `[...]` で囲む。本リポジトリのスキルは引数省略時にユーザーへ確認する設計のため、
  実質すべて任意扱いとし `<...>`（必須）は使わない。
- ラベルは日本語可（`[ファイルパス]`）。識別子そのものを渡す場合は英字可（`[owner/repo]`）。
- 択一は `|` 区切り（`[課題キー|検索キーワード]`）、可変長は `...` を付ける（`[対象ファイル...]`）。
- 複数引数はスペース区切りで位置順に並べる（`[対象ファイル...] [ラウンド数]`）。
- 値はダブルクォートで囲む。`[` 始まりの裸の値は YAML がフロー配列として解釈しうるため。

```yaml
---
name: format--backlog-notation
description: ファイルの内容をBacklog記法に変換して出力するスキル
argument-hint: "[ファイルパス]"
---
```

## 付けない基準

現在のブランチ・作業ツリーの差分・`.claude/` の全走査など、**引数なしで完結するスキルには付けない**。
実在しない引数を提示すると誤誘導になる。

## 注意

`argument-hint` はオートコンプリートの**表示専用**で、スキルの挙動は変えない。引数の受け取り方を
規定したい場合は SKILL.md 本文に `$ARGUMENTS` を書く（本フィールドだけでは不十分）。
